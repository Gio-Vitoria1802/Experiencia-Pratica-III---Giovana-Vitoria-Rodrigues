Café com Leite

Projeto desenvolvido para as Experiências Práticas III e IV – UNICEP
Autora: Giovana Vitória Rodrigues

Sobre o Projeto

O Café com Leite é um site responsivo criado como prática de desenvolvimento front-end. O projeto evoluiu ao longo das entregas, incorporando SPA simples, manipulação de DOM, validação de formulários, acessibilidade WCAG 2.1, controle de versão com GitFlow e deploy em ambiente de produção.

Funcionalidades Principais
Single Page Application (SPA)

Carregamento dinâmico de seções através de JavaScript, sem recarregar a página.
Templates organizados e manipulados via DOM.

Manipulação do DOM
Menu responsivo com botão hambúrguer, injeção dinâmica de conteúdo e scripts modulares.
Validação de Formulário
Verificação de campos obrigatórios, avisos de erro e feedback visual ao usuário.

Modo Escuro.

GitFlow Implementado

Fluxo seguido: main → develop → feature/*
Commits escritos em padrão semântico:

fix: correções
style: ajustes visuais
docs: documentação
refactor: melhorias internas
